Projeto final

Durante meu estágio na 99, desenvolvemos um projeto para resolver um dos maiores índices de reclamações dos motoristas: o passageiro sujou/danificou o veículo. Pensando nisso, criamos um sistema de controle baseando-se no histórico de cada passageiro, para que o motorista possa avaliar se deseja ou não aceitar a corrida. Além disso, demos a ideia de criar um sistema de pontuação inspirado no Airbnb, onde o cliente consegue ver suas principais avaliações e a porcentagem de cada uma delas, buscando melhorar constantemente.
